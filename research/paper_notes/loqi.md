## Problem
Generate low-energy (AIMNet2/QM-quality) 3D conformers of drug-like molecules, with explicit stereochemistry control, at scale.

## Method (from code)
- Built on Megalodon (README "Note on Implementation"). Model `megav3conf` (configs `src/loqi/configs/loqi.yaml`, `loqi_flow.yaml`), 10 layers, equivariant transformer.
- Only coordinates are generated: `x` uses `continuous_flow_matching` (loqi_flow.yaml:49-62) or diffusion (loqi.yaml); atom types `h`, bonds `edge_attr`, and `charges` use `interpolant_type: "discrete_null"` (loqi_flow.yaml:63-76), which the builder documents as "variables we just want to pass in and not noise/denoise" (src/megalodon/interpolant/builder.py:188-190).
- Formal charges are one-hot (6 classes, offset 2 → charges −2…+3) and concatenated onto the atom-type one-hot (`concat: 'h'`, loqi_flow.yaml:71-76; module.py:270-287); hence `atom_classes: 23` = 17 elements + 6 charge bins (loqi_flow.yaml:81).
- Stereo conditioning by graph augmentation: extra edge types 5/6 (E/Z) and 7/8 (tetrahedral) added to a fully connected graph (featurize.py:21-22, 77-86).
- Loss: MSE on `x` only (loqi_flow.yaml:31-38).

## Data
ChEMBL3D. Training set construction (`data_processing/process_chembl3d.py`): for **each `mol_id`** keep the single absolute-energy-minimum conformer across all its conformers and stereo classes (lines 78-121). Split by **parent** ChEMBL ID with variant suffixes `CHEMBL123_k` grouped (lines 130-187), so all variants of a parent go to the same split — and every variant is kept as its own training example. Kekulised topology (line 317) from the release SDF; graph built by `raw_to_pyg` (utils_data.py:330) → `mol_to_torch_geometric`, which stores `atom.GetFormalCharge()` per atom (utils_data.py:304). Processed train split has charged atoms: N +1 8.2%, O −1 4.1% of N/O atoms (train_charges_h.npy; see chembl3d.md).

## Inputs/outputs (exact)
Input per molecule (featurize.py:53-97, `mol_to_data`):
- `x`: element index for every atom **including explicit H** (17-element encoder),
- `charges`: per-atom formal charge from RDKit (`atom.GetFormalCharge()`, line 75),
- `edge_index/edge_attr`: Kekulé bond orders (1/2/3; aromatic flags cleared, lines 61-67) + stereo edges,
- `pos`: zeros (prior sample replaces it) unless `use_3d_input`.
Hydrogens: added by RDKit `Chem.AddHs` on the canonicalised input SMILES (validation.py:61) unless `--no-add-hs`; the number/placement of H therefore come from the input SMILES as written (RDKit implicit-H valence rules). No protonation, neutralisation, tautomer or pKa step exists anywhere in the repo (grep for protonat/pH/pKa/tautomer/epik/dimorphite/openeye over *.py/*.yaml/*.md: only hit is the abstract in README.md:55).
Output: RDKit Mol with N conformers of exactly the input topology (`conformers_to_mol`, featurize.py:239-253; api.py:160-233). Energy evaluation uses AIMNet2 with total charge = `Chem.GetFormalCharge(mol)` (src/megalodon/metrics/molecule_metrics_aimnet2.py:156).

## Limitations
- Conditional p(x | G_z): one fixed topology per call; no state variable z, no pH.
- Training targets the single lowest-energy conformer per `mol_id` (process_chembl3d.py:78-121), i.e. a low-energy-structure generator, not a Boltzmann ensemble.
- Supported elements limited to AIMNet2's set; disconnected fragments only in permissive mode (featurize.py:130-158).
- Non-carbon chirality control limited (README v1.1.0).

## Relevance to p(z,x|G,h)
LoQI covers the x | z factor: a QM-informed, charge-aware, explicit-H conformer generator conditioned on a *given* protonation microstate. It exposes formal charges as conditioning features and was trained on a mix of neutral and charged microstates, which is exactly the x|z capability a joint model needs. It does not cover z | G, h (state selection, pH conditioning, populations). A sequential FixpKa/Epik → LoQI pipeline is therefore an obvious strong baseline for the proposal.
