# Q-P3-009 (from coding planner P3, round 5) -> R-JOINT

**Concerns:** EXP-1 §5.2 M1 ("Train only the V2 geometry head (torsion loss weight 0, τ noise still applied) on the
full QM9 training set"), §6 cost row M1 ("0.3 × 11.7 × 3"), §4 arm A11; code `torsional-diffusion/diffusion/

**Question.** In M1, which parameters train?
- (a) The whole FlexiTors network (trunk + geometry head) from random initialisation, loss = geometry loss only. The
  cost basis 0.3 × 11.7 GPU-h assumes a full forward + backward through the trunk, which fits (a).
- (b) Trunk initialised from CTRL_rematch s0 (or the released model) and frozen; only `VectorL1oHead` trains. Cheaper
  backward, but the second clock t must enter through the λ-embedding slot (`score_model.py:194-199`), which changes the
  input width of `node_embedding` / `edge_embedding` (`:69-79`), so a TD checkpoint cannot be loaded strictly.
- (c) Trunk initialised from CTRL_rematch and fine-tuned with the geometry loss.

**Decision at stake.** Whether the Gate-0 result says "geometry can be learned from scratch by this architecture" (a)
or "a torsion-trained representation already carries L" (b/c); the GPU cost (b is cheaper; unmeasured); and whether
the V2 stage of M2 starts from the M1 checkpoint.

**Default used in plan_P3 (PENDING Q-P3-009):** (a), seed 0, clock t through `lambda_embed_dim = 32` (the round-2 S4
mechanism). Checkpoint selection by validation geometry loss.


## Answer (JOINT)
**Option (a)**, as in your default: the whole network trains from random initialisation on the geometry loss only,
seed 0, with the clock through `lambda_embed_dim = 32`. Checkpoints are selected by validation geometry loss (§10.3).
- Reasons: it matches the cost basis; (b) cannot load a TD checkpoint strictly; and Gate 0 should answer whether this
  architecture learns L, not whether a torsion-trained representation already carries it.
- (c) can be a later ablation if Gate 0 passes.
- **A4 (M2) trains from scratch**, not from the M1 checkpoint, to keep epoch counts matched with A0/A3 (Q-P2-005).
