# Q-P3-002 (from coding planner P3, round 5) -> R-JOINT

**Concerns:** EXP-1 §2.2 steps 4–6 (stochastic interpolant, ET-Flow Eq. 2–5 [E-JOINT-076]), §2.2 "Sampling", §2.5
row "L, V2 bridge"; implementation in `flexitors/training/transforms.py` and `flexitors/sampling/joint_sampler.py`.

**Questions.**
1. γ(t) = σ_b√(t(1−t)) has γ'(t) = σ_b(1−2t)/(2√(t(1−t))), which diverges at t = 0 and t = 1, so the target
   u = P_L(x_t)[x_G' − x_R' + γ'(t) P_L(x_R') z] is unbounded for t ~ U[0,1]. Does ET-Flow clip t to [ε, 1−ε] (which
   ε?) or use another parameterisation of the noise term? Which should M1 use?
2. Sampling is "geometry Euler step x ← x + Δt·P_L(x) v" (deterministic, no noise injection) with Δt = 1/N. Is the
   ODE (no γ noise at sampling) intended, and is N = 20 (TD's step count, same NFE) the M1 setting?
3. The loss normalisation "/(3n − 6 − m)" (step 6): per molecule (mean over the batch of per-molecule normalised
   squared norms) or pooled over the batch?

**Decision at stake.** Training stability of all three A11 runs (≈ 10.5 GPU-h, ceiling 16): a NaN or exploding loss
near t → 0 or 1 would waste the whole gate. Also the M1 sampler's NFE.

**Default used in plan_P3 (PENDING Q-P3-002):** t ~ U[ε, 1−ε] with ε = 1e-3 (logged); ODE Euler sampling with N = 20
uniform steps from t = 0 to 1; per-molecule normalisation, then batch mean. The 1-epoch smoke run checks that the loss
is finite and bounded across t bins before M1 starts.


## Answer (JOINT)
EXP-1 revised (§10.1.4, §10.2).
1. **ET-Flow gives no clipping rule.** It trains with "t U (0, 1)" (PDF p. 4) [E-JOINT-082]. The divergence is removed
   by switching to **x₁ prediction** (HarmonicFlow PDF p. 4; PuckerFlow SI Alg. 1, PDF p. 20) [E-JOINT-080, -081],
   with t ~ U[0, 1] and no ε. The smoke run should still check that the loss is finite per t bin.
2. **Yes: deterministic Euler ODE, N = 20 uniform steps.** With x₁ prediction the update is
   x ← x + Δt·P_W(x)(x̂₁ − x)/(1 − t), and the final step lands on x̂₁. Torsion restoration is on (Q-P2-002).
   ET-Flow's stochastic sampling in [0.8, 1] (PDF p. 5) is a later ablation.
3. **Per molecule**, divided by rank(P_W), then the batch mean (as Q-P1-001.6).
