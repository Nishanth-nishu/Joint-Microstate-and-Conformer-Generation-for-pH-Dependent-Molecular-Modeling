**Question.**
1. For a molecule without TD-rotatable bonds, W is empty and P_W only removes rigid motion, so after Kabsch
   alignment x_R + P_W(x_G − x_R) ≈ x_G and the M0 recovery is ≈ 100 % by construction. Rigid-stratum molecules with
   only methyl/OH rotors have H-terminated W rows only. Should the kill criterion be applied to molecules with ≥ 1
   heavy rotatable bond and a ring of ≥ 4 atoms instead (keeping the rigid stratum as a sanity row)?
2. M0 uses own-conformer GT (ORACLE) to make a go/no-go decision. Should that decision use validation-set pairs
   (paired cache) with test pairs reported only?
3. §5.2 states the Gate-0 evaluation on the 289 test molecules while §4 control 8 picks σ_b on the validation rigid
   stratum. Should both the σ_b choice and the GO decision use validation strata (thresholds 0.10 Å and 20 % kept
   absolute, with validation ETKDG/MMFF baselines reported), with the test numbers produced once afterwards?
4. The "> 10° ring-dihedral share" baseline (49.6 %) compares each seed with its matched GT conformer. A geometry head
   can produce a valid pucker that matches a different GT conformer. Is the paired metric primary, with the
   best-over-GT variant reported beside it?

**Decision at stake:** whether M0 can kill anything, and whether the first GPU gate is decided on the test set.

**Default used (PENDING Q-P2-004):** (1) yes; (2) yes, validation decides; (3) yes, validation decides, test once;
(4) paired metric primary (comparable with 49.6 %), best-over-GT reported.


## Answer (JOINT)
EXP-1 revised (§10.3). All four of your defaults are accepted; points 1–3 are spec flaws that are now fixed.
1. **Yes.** The old criterion was vacuous. M0 is now an oracle-velocity integration test on molecules with ≥ 1 heavy
   rotatable bond and a ≥ 4-atom ring, with rigid rows kept as a sanity row (details in the Q-P1-003 answer).
2. **Yes: validation pairs decide** (`cache_paired.val`); test pairs are reported once.
3. **Yes: validation decides both σ_b\* and GO**, on a fixed 1000-molecule split-1 subset with CPU-computed ETKDG/MMFF
   baselines. Thresholds stay absolute, with a scaling rule if a validation baseline differs from test by > 10 %
   relative. Test is read once afterwards.
4. **Yes: the paired metric is primary** and the best-over-GT variant is reported beside it.
