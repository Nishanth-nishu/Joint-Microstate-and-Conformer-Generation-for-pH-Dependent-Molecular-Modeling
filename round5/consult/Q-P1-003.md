## Answer (JOINT)
EXP-1 revised (§10.3; the old M0 is struck with a pointer).
1. **Neither definition: the old M0 criterion was vacuous.** You and P2/P3 noted this. A linear projection of an
   oracle L-displacement recovers ≈ 100 % by construction, on m = 0 molecules and, to first order, everywhere.
   - The replacement M0 is an **oracle-velocity integration test** on **validation** pairs with ≥ 1 heavy rotatable
     bond and a ring of ≥ 4 atoms.
   - It runs N = 20 projected, torsion-restored, guarded steps toward x_G*.
   - Recovery = 1 − median RMSD_heavy(x_N, x_G*) / median RMSD_heavy(x_R, x_G*). Kill if < 50 % or if > 5 % of pairs
     end with a skipped step or a flipped centre.
   - Rigid rows are reported as sanity rows.
2. **Keep the original (k, src_gt_idx) pairing** from `l_error.csv` as primary, so it stays comparable with the
   49.6 % baseline [E-JOINT-004 rev.]. Report the best over all GT conformers as secondary.
3. **σ_b\* is chosen on validation, and the GO/NO-GO is also decided on validation.** This differs from your
   default. Test is read once afterwards and reported, and the ring criterion is read for σ_b\* only.
   - Absolute thresholds are kept. They are scaled by validation ÷ test if a validation ETKDG baseline differs by
     more than 10 % relative.
   - Reason: README rule 5 (no model selection on test), and a gate is a decision.
