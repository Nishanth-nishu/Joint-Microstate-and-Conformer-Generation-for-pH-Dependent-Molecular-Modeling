# Q-P2-003 (from coding planner P2, round 5) → R-JOINT

**Concerns:** EXP-1 §2.2 Training steps 3–5 (same Δτ on both endpoints; x_t = interp(x_R', x_G', t) + γ(t) P(x_R') z;
target u = P(x_t)[x_G' − x_R' + γ'(t) P(x_R') z]), §2.8 (chirality guard; reject-and-resample is specified for V3a's
forward kernel only).

**Question.**
1. x_R = `data.pos[k]` is an RDKit conformer whose torsions were matched to GT conformer k by differential evolution,
   so residual rotatable-torsion differences remain (not measured in the spec). P_W removes their first-order part
   only; the rest enters the "L" target. Should the target instead be built from a "pure-L" GT, x_G* = x_G with its m
   TD-quadruple dihedrals set to x_R's values by rigid side rotations (exact, changes no bond/angle), so that
   x_G* − x_R contains no torsion difference by construction?
2. With σ_b up to 0.3 Å, the noise term γ(t) P z can flip tetrahedral centres in x_t (V5 saw 1 flip in 20 random
   0.3 Å RMS steps). Should V2 training reject and resample such x_t (as §2.8 specifies for V3a), or keep them?

**Decision at stake:** the training target of the geometry head (what "L" means in V2) and the training distribution.

**Default used (PENDING Q-P2-003):** the spec's target, plus per-sample diagnostics (residual |Δτ| on TD quadruples;
fraction of ‖x_G − x_R‖² removed by P_W; chirality changes of x_t) logged every epoch of the smoke and M1; flipped x_t
counted, not rejected.


## Answer (JOINT)
EXP-1 revised (§10.1.3, §10.1.5).
1. **Yes, use the pure-L target x_G\*.**
   - Construction: set x_G's m W-quadruple dihedrals (heavy-first rule, Q-P2-001) to x_R's values by rigid side
     rotations with `modify_conformer`, then Kabsch-align x_G\* to x_R on heavy atoms. Unit-test the sign convention
     of `torsion.py:68` ("positive rotation if pointing inwards") against atan2.
   - Effect: x_G\* − x_R then has no W-dihedral difference by construction, and the residual DE torsion mismatch
     stays with the torsion factor. That factor is trained on x_R's torsions, as in TD. Keep your per-sample
     diagnostics.
2. **Reject and resample z** (≤ 5 tries); if x_t still flips, mask the geometry loss and count it. This is the same
   as Q-P1-001.4.
