# Q-P2-011 (from coding planner P2, round 5) → R-SAMPLE (EVAL owner; cc R-JOINT)

**Concerns:** EVAL §3 (failure handling, both conventions; molecule-level failures only), EXP-1 §3 row 5 ("Validity:
sanitisable, connectivity preserved … failures counted, never dropped"), EXP-1 §2.6 (constraint-layer skips).

**Question.** Exp 1's geometry steps can, rarely, return a conformer whose bond perception from 3D no longer equals the
input graph, or that clashes. `evaluate_confs.py` scores it anyway (it compares with `GetBestRMS` on the input graph,
`:111-115`). How should such conformers enter AMR-R / COV-R? Options: (a) keep them (evaluator unchanged; counts
reported); (b) set their RMSD columns to +∞, so they can never match while the sample count stays 2K; (c) drop them
(fewer samples: recall falls, precision rises).

**Decision at stake:** a pre-declared conformer-level failure convention, needed before the Gate-0 evaluation.

**Default used (PENDING Q-P2-011):** (a) primary, (b) secondary, counts per arm and seed; (c) never.

## Answer (SAMPLE, EVAL owner; cc R-JOINT)
Date 2026-10-16. Spec revised: EVAL §3.1 (new).

**Your default is adopted.**
- **(a) Primary.** The evaluator is unchanged: invalid conformers are scored like any other, as in TD and every
  published table. Invalid counts are printed per arm and seed.
- **(b) Secondary, "validity-adjusted".** The slot is kept, so the output stays 2K.
  - Recall RMSD is set to +∞.
  - In COV-P an invalid conformer counts as uncovered.
  - AMR-P is computed over valid conformers only, with the invalid count beside it, because +∞ would make the mean
    undefined.
- **(c) Never drop.** EXP-1 §3 row 5 already says "failures counted, never dropped". Dropping changes the sample count:
  recall falls and precision rises.
- **Definition of invalid:** sanitisation fails, 3D bond perception ≠ input graph, a clash, or stereo ≠ input
  (EXP-1 row 5, EXP-3).
- A method that filters invalid conformers before output must declare the filter as part of the method, keep exactly
  2K, and report it in its own row.
