## Questions
1. **Endpoint handling of the interpolant.** The target u contains γ′(t)·P_W z with γ′(t) = σ_b(1 − 2t)/(2√(t(1 − t))),
   which diverges as t → 0 or 1 (ET-Flow Eq. 2–5, E-JOINT-076). The spec draws t ~ U[0, 1]. Should t be drawn from
   U[t_ε, 1 − t_ε] (which t_ε?), should γ′ be clipped, or does the ET-Flow source specify something else?
2. **σ fed to the network in τ-frozen geometry sampling** (M1 evaluation, A6/A6b sampler). Torsions are not noised,
   so should the torsion-clock input be σ_min throughout, or follow TD's geometric schedule in step with t?
3. **"Train only the V2 geometry head"** (§5.2 M1). Is the whole network trained from scratch on the geometry loss only
   (w_τ = 0, τ noise still applied; this is what the 0.3 × 11.7 GPU-h cost assumes)? Or is a frozen pretrained trunk
   (e.g. CTRL_rematch s0) used with only the head trained? Note that a frozen TD trunk has no clock input
   (`lambda_embed_dim = 0`), so t could then enter only the head.
4. **Chirality in V2 training samples.** §2.8 requires rejection for DAgger roll-outs and V3a noise. Should noised V2
   interpolant states x_t that flip a centre also be rejected and resampled, or only counted?
5. **Geometry clock embedding.** Is it acceptable to feed t through TD's λ path with `lambda_embed_dim = 32` (as S4)?
6. **Loss reduction.** Per-molecule sum divided by (3n − 6 − m), then the mean over the molecules in the batch.
   Please confirm.

## Answer (JOINT)
EXP-1 revised (Revision 2, §10.1–§10.2).
1. **Endpoints: no ε.** I changed the V2 head to endpoint (x₁) prediction, so t ~ U[0, 1] with no clipping, and the
   loss is ‖P_W(x_t)(x̂₁ − x_G*′)‖². ET-Flow states only "t U (0, 1)" and gives no clipping rule (PDF p. 4)
   [E-JOINT-082]. HarmonicFlow (PDF p. 4) says: "we find it helpful to parameterize v to predict x1 instead of
   (x1 - x0)" [E-JOINT-080]. PuckerFlow trains with x₁ prediction (SI Alg. 1, PDF p. 20) [E-JOINT-081]. This removes
   the γ′(t) divergence instead of patching it.
2. **σ in τ-frozen sampling = σ_min throughout** (§10.2). The torsions are clean, and σ_min = 0.01π is inside the
   training range.
3. **Whole network from scratch** on the geometry loss only (w_τ = 0, τ noise applied), option (a) (§10.3). This
   matches the 0.3 × 11.7 GPU-h basis. A TD checkpoint cannot be loaded strictly once the clock widens the embedding.
   Gate 0 asks "can this architecture learn L". A4 later trains from scratch too.
4. **Resample, then mask.** Resample z up to 5 times; if x_t still flips a centre, mask the geometry loss for that
   sample and count it (§10.1.5). This is consistent with the V3a rule in §2.8.
5. **Yes**: `lambda_embed_dim = 32`, the S4 path [E-JOINT-023].
6. **Confirmed**, with one change: divide by rank(P_W) of each molecule rather than the nominal 3n − 6 − m, because
   near-linear rows can be dropped (Q-P2-001). Then take the batch mean.
